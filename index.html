Customer Workflow

客户使用流程

01

打开网站

客户使用 Microsoft Edge 或 Google Chrome 打开 CORVON GNSS 网站，进入在线工具。

02

连接模块

将 GNSS 模块通过 USB 转串口连接电脑，并在浏览器弹窗中授权访问对应串口。

03

开始调试

点击打开串口，工具会自动识别常用波特率和输出模式，实时展示定位与报文数据。

Features

客户常用功能

原始数据

显示私有协议原始字节和输出频率，便于检查模块实时输出。

协议帧

显示帧序号、移动站 SN、定位状态、坐标和校验结果。

移动站

按 SN 查看多个移动站的定位状态、卫星数、坐标、高度和速度。

地图定位

同时显示多个基站位置，未定位或超时的站点保留位置并置灰。

Requirements

运行要求

在线访问建议使用桌面版 Microsoft Edge 或 Google Chrome。串口连接依赖浏览器 Web Serial API，需要 HTTPS 或本地服务环境，并由用户主动授权访问串口设备。

  • 推荐浏览器：桌面版 Microsoft Edge / Google Chrome
  • 在线网站：GitHub Pages 使用 HTTPS，适合客户快速打开
  • 现场调试：也可以运行本地服务 打开GNSS网页版.bat
  • 串口权限：浏览器会弹出设备选择框，需要客户手动确认
  • 说明书：CORVON GNSS Tool操作说明书v1.0.pdf
